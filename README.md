# 🏋️‍♂️ Landing Page - Neto Personal Trainer

Landing page premium, responsiva e de alta conversão desenvolvida para o Personal Trainer **Francisco de Assis (Neto)**, focada na captação de alunos para consultoria online e presencial.

---

## 🚀 Funcionalidades Principais

*   **Hero Section:** Apresentação de alto impacto com foto de perfil e CTA pulsante para o WhatsApp.
*   **Diferenciais:** Grade de benefícios focada em segurança, ciência e metodologia.
*   **Cards por Objetivos:** Direcionamento estratégico para Emagrecimento, Hipertrofia ou Saúde.
*   **Prova Social:** Seção de depoimentos de alunos reais para quebra de objeções.
*   **Planos & Preços:** Ancoragem de valor entre os planos *Essencial* e *Premium*.
*   **FAQ Integrado:** Seção de perguntas frequentes nativa via tag `<details>`.

---

## 🛠️ Tecnologias

*   HTML5 (Estrutura semântica e acessibilidade)
*   CSS3 (Design moderno, Flexbox/Grid e Responsividade)
*   JavaScript Vanilla (Interações e eventos)
*   Font Awesome v6.0 (Ícones)
*   Google Fonts (Montserrat)
